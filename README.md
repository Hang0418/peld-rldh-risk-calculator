# PELD-RLDH Risk Calculator

A privacy-preserving browser calculator for the frozen multicenter PELD-RLDH prediction model (`PELD_RLDH_V5_20260810`). All inference occurs locally; the site has no patient-data backend.

## Scientific status

- Eight preoperative predictors are transformed with the exported restricted cubic splines, scaling parameters, categorical encoding, ridge coefficients, and Platt calibration.
- H5 and H6 were not used to select, tune, or recalibrate the displayed model.
- This is a research and reproducibility companion, not a clinical directive.
- The operational outcome definition and fixed prediction horizon remain an author query. The interface therefore does not label the output as “2-year risk.”

See [model card](docs/model_card.md), [predictor definitions](docs/predictor_definitions.md), [methodology](docs/methodology.md), and [validation summary](docs/validation_summary.md).

## Run locally

Requirements: Node.js 22 and pnpm 11.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Open `http://localhost:3000`.

## Validate

```bash
pnpm run build
pnpm run test:model
pnpm run test:render
pnpm run lint
```

The numerical test compares the JavaScript implementation against 72 deterministic synthetic reference cases generated by the independent frozen Python equation. No patient records are used.

## Deploy

`pnpm run build:pages` produces a static `dist/client/index.html` plus assets. The included GitHub Actions workflow publishes `dist/client` to GitHub Pages. The same application can also be deployed as a vinext worker.
